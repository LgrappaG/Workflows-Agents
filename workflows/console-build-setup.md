# Console Build Setup (PlayStation & Xbox)

This workflow covers cross-platform console development prerequisites, SDK setup, certification requirements, and deployment to PlayStation 5 and Xbox Series X|S.

## Prerequisites

- Registered publisher account with Sony (PlayStation) and/or Microsoft (Xbox)
- Dev kit hardware (PS5/Xbox Series X) or virtual dev kit
- Console SDK installed (PS5 SDK, Xbox SDK)
- Unity 2022 LTS with console build support
- TLS/SSL certificate for secure communication
- 50GB free disk space

## Context

Console development requires publisher registration, secure development environments, and adherence to strict certification guidelines. This workflow streamlines the process.

// turbo-all

## Phase 1: Publisher Registration & Certification

1. **PlayStation Network Developer Program:**
   - Register at playstation.com/ps-network-developer
   - Submit publisher information
   - Receive publisher ID
   - Wait for approval (typically 2-4 weeks)

2. **Xbox ID@Xbox Program:**
   - Enroll at microsoft.com/en-us/id-at-xbox
   - Complete identity verification
   - Provide tax information (Form W-9 for US)
   - Receive Xbox Live creator ID

3. **Developer Documentation Access:**
   - PS5: Access Sony's Superdata portal
   - Xbox: Download Xbox Developer Kit (XDK) from Partner Center
   - Both: Review certification guidelines (100+ page documents)

## Phase 2: Console SDK Installation & Environment

1. **PlayStation 5 SDK Setup:**
   ```bash
   # 1. Download ProDG or SDK from Superdata
   # 2. Install to dedicated partition (requires large storage)
   # 3. Accept license agreements
   # 4. Configure development kit network:

   # SSH into PS5 dev kit
   ssh devkit@[PS5_IP_ADDRESS]
   ```

2. **Xbox Series X SDK Setup:**
   ```bash
   # 1. Install Xbox OneD (for Series X development)
   # 2. Download Partner Center tools
   # 3. Configure dev kit:

   # Command to register console
   xbapp /devkit:setip [XBOX_IP_ADDRESS]
   ```

3. **Unity Console Build Support:**
   ```plaintext
   - Download console-specific Unity modules
   - PS5 module from: Unity Download Archive → PS5 Support
   - Xbox Series X module from: Xbox Developer Kit → Unity Integration
   - Install to your Unity version
   ```

## Phase 3: Project Configuration for Consoles

1. **PS5 Player Settings:**
   ```plaintext
   File → Build Settings → PS5
   - Target Platform: PS5
   - Graphics: Use PS5 optimized rendering pipeline
   - Shader Quality: High (PS5 has strong GPU)
   - Resolution: 1440p or 4K (target 120 FPS for Series X)
   ```

2. **Xbox Series X Settings:**
   ```plaintext
   File → Build Settings → Xbox Series X
   - Target Platform: Xbox Series X
   - Resolution: 4K / 120 FPS or 1440p / 120 FPS
   - Smart Delivery: Enable (handles Series S version too)
   - Variable Rate Shading: Enable (Xbox series exclusive)
   ```

3. **Console-Specific Graphics:**
   ```csharp
   #if UNITY_PS5
   // PS5: Use PlayStation-specific features
   GraphicsSettings.SetShaderMode(ShaderHardwareTier.Tier3);
   #elif UNITY_XBOX_SERIES_X
   // Xbox: Use Xbox Series X optimizations
   SystemInfo.supportsComputeShaders = true;
   #endif
   ```

## Phase 4: Certification Compliance Implementation

1. **Required Features for Submission:**
   ```markdown
   PlayStation 5 Requirements:
   - DualSense controller haptics integration
   - SSD I/O optimization (fast loading <5s)
   - Activity cards and system features
   - Accessibility features (WCAG)

   Xbox Series X Requirements:
   - Quick Resume support (game state preservation)
   - Xbox Velocity Architecture (SSD optimization)
   - Accessibility features
   - Game Pass integration
   ```

2. **Implement Required APIs:**
   ```csharp
   // PS5: Haptic feedback example
   #if UNITY_PS5
   using PlayStation.PS5.Input;

   PS5Controller controller = GetComponent<PS5Controller>();
   controller.SetPlayStationRumble(intensity: 0.8f);
   #endif
   ```

3. **Network & Security:**
   ```plaintext
   Console Network Requirements:
   - Implement PSN (PlayStation Network) authentication
   - Implement Xbox Live authentication
   - Support cross-play (optional but recommended)
   - Encrypt all network traffic (TLS 1.2+)
   ```

## Phase 5: Development Kit Testing

1. **Connect Development Console:**
   ```bash
   # PS5
   ps5_dev_kit_ip=$(networksetup -listallnetworkservices | grep "Wi-Fi" -A 1 | tail -1)
   ssh devkit@$ps5_dev_kit_ip

   # Xbox Series X
   xbapp /devkit:ip [XBOX_IP_ADDRESS]
   ```

2. **Deploy to Dev Kit:**
   ```plaintext
   Unity Editor → Build Settings → Build and Run
   - Select PS5 or Xbox Series X platform
   - Choose mounted dev kit from dropdown
   - Build takes 10-30 minutes (first time)
   - Game launches on dev kit automatically
   ```

3. **Test Console Features:**
   - [ ] Haptic feedback (PS5 DualSense)
   - [ ] Activity cards (PS5) / Game Hub (Xbox)
   - [ ] Quick Resume / Suspend-Resume cycle
   - [ ] Cloud save integration
   - [ ] Controller connectivity
   - [ ] Network connectivity

## Phase 6: Certification Submission Process

1. **Prepare Submission Package:**
   ```plaintext
   Required deliverables:
   - Build files (compiled for both platforms)
   - Marketing materials:
     - Game title, description, ESRB rating
     - Screenshots (at least 7)
     - Trailer (30-60 seconds)
   - Testing notes and known issues
   - System resource requirements
   ```

2. **Submit Through Publisher Portal:**
   ```plaintext
   PlayStation:
   - Superdata → Submissions → Create New Submission
   - Upload build + marketing assets
   - Select target regions/age ratings
   - Agree to certification checklist

   Xbox:
   - Partner Center → Certification → Create New Submission
   - Upload XVC file (compiled Xbox version)
   - Provide detailed testing instructions
   - Target publish date
   ```

3. **Certification Review Timeline:**
   ```plaintext
   Expected timelines:
   - PS5: 5-7 business days
   - Xbox: 3-5 business days
   - Includes automated scanning + manual review
   ```

## Phase 7: Managing Certification Feedback

1. **Typical Certification Issues:**
   ```markdown
   Common rejection reasons:
   - Performance: Frame drops, crashes, poor load times
   - Security: SSL/TLS vulnerabilities, auth flaws
   - Compliance: WCAG accessibility failures, rating mismatches
   - Network: Connection timeouts, cloud save failures
   - Features: Missing required DS4/controller features
   ```

2. **Response Process:**
   ```plaintext
   - Sony/Microsoft comments on build
   - Team has 30 days to respond
   - Can resubmit build or request Exempt status
   - Second submission typically faster (3-5 days)
   ```

## Phase 8: Post-Launch & Updates

1. **Version Management:**
   ```plaintext
   - Version 1.0.0: Initial release
   - Version numbering: Major.Minor.Patch
   - Each update requires re-certification
   - Patches typically 1-3 day certification
   ```

2. **Cloud Saves & Patches:**
   - Enable cloud saves integration
   - Register patch builds before release
   - Test backwards compatibility

3. **Monitor Performance:**
   - Track crash reports from certification
   - Monitor player connectivity issues
   - Collect telemetry on feature adoption

## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| Dev kit not recognized in Unity | Verify network connectivity, restart dev kit, update Unity SDK module |
| Build fails with "SDK not found" | Ensure console SDK path set in Editor Preferences |
| Certification rejected for performance | Profile with console profiler, optimize draw calls and memory |
| Cross-play connectivity fails | Verify PSN/Live endpoints reachable, check firewall rules |
| Cloud save issues on certification | Test with multiple PSN/Live accounts, verify data format |
