# Android-Specific Setup & Optimization

This workflow guides you through setting up a Unity project for high-performance Android development, covering SDK configuration, build optimization, platform-specific APIs, and device testing.

## Prerequisites

- Unity 2022 LTS or newer
- Android SDK 31+ installed
- JDK 11+ or OpenJDK
- Unity Android Build Support module installed
- Target device or Android emulator (API 28+)
- 2GB free disk space for tools

## Context

Android development requires specific optimizations due to device fragmentation, limited hardware resources, and power constraints. This workflow ensures your project leverages Android-specific features while maintaining quality.

// turbo-all

## Phase 1: Android SDK & Environment Setup

1. **Install Android Build Support in Unity:**
   ```bash
   # Use UnityHub to add Android module to your Unity version
   # Or manually: Editor Settings → External Tools → Android SDK
   # Set paths for:
   # - Android SDK Location
   # - JDK Location
   # - NDK Location (for native code)
   ```

2. **Verify SDK Installation:**
   ```bash
   # Check Android SDK version
   cat "%ANDROID_HOME%/system-images/android-*/default/build.prop" 2>/dev/null || echo "SDK found at $ANDROID_HOME"

   # List installed SDK platforms
   "%ANDROID_HOME%/tools/bin/sdkmanager" --list > sdk_versions.txt
   ```

3. **Update Build Tools:**
   ```bash
   # Install minimum required API levels
   sdkmanager "build-tools;34.0.0" "platforms;android-34" "platforms;android-31"
   ```

## Phase 2: Android Player Settings Configuration

1. **Configure Player Settings:**
   - **File → Build Settings → Android**
   - **Player Settings (gear icon):**
     - **Resolution**: Portrait or Landscape (match your game)
     - **Supported Aspects**: Phone and Tablet
     - **Orientation**: Lock to Primary Orientation

2. **Graphics Configuration:**
   - **Graphics APIs**: Recommend OpenGL ES 3.0 + Vulkan
   - **Disable**: OpenGL ES 2.0 (legacy)
   - **Multithreading Rendering**: Enable for performance
   - **GPU Instancing**: Enable

3. **API Level Configuration:**
   ```
   Minimum API Level: 28 (Android 9)
   Target API Level: 34 (Android 14) - Latest recommended
   ```

4. **Scripting Options:**
   - **Scripting Backend**: IL2CPP (recommended for performance)
   - **Managed Stripping Level**: High
   - **Strip Engine Code**: Enable

## Phase 3: Performance Optimization Settings

1. **Memory & Rendering Optimization:**
   ```plaintext
   Quality Settings (Edit → Project Settings → Quality)
   - Target Frame Rate: Set to 60 FPS (or 90 for 120Hz devices)
   - V Sync Count: Full V Sync
   - Anti-Aliasing: 2x or 4x (depends on target devices)
   - Texture Quality: Half or Full (depends on VRAM)
   ```

2. **Physics Configuration:**
   - **Max Angular Velocity**: 7 (default)
   - **Default Solver Iterations**: 6
   - **Disable**: Gravity if not needed

3. **Audio Settings:**
   - **Audio DSP Buffer Size**: Best Latency (for real-time audio)
   - **Disable**: Audio Reverb Zones if not used
   - **Compression**: Use Vorbis for .ogg files

## Phase 4: Android-Specific Plugin Integration

1. **Permission Handling:**
   ```csharp
   // Use AndroidJavaClass for native permission requests
   using UnityEngine.Android;

   if (!Permission.HasUserAuthorizedPermission(Permission.ExternalStorageRead)) {
       Permission.RequestUserPermission(Permission.ExternalStorageRead);
   }
   ```

2. **Native Integration Points:**
   ```plaintext
   Common Android Java Interop:
   - AndroidJavaClass for static calls
   - AndroidJavaObject for instances
   - AndroidJavaProxy for callbacks

   Example: Get device brand
   AndroidJavaClass build = new AndroidJavaClass("android.os.Build");
   string brand = build.GetStatic<string>("BRAND");
   ```

3. **Gradle Configuration:**
   - **Build System**: Gradle (default)
   - **MIN_API_LEVEL**: 28
   - **TARGET_API_LEVEL**: 34
   - **Custom Gradle Template**: Enable if using plugins

## Phase 5: Testing & Device Deployment

1. **Enable Debug Bridge (ADB):**
   ```bash
   adb devices -l
   adb reverse tcp:34999 tcp:34999  # Port forwarding if needed
   ```

2. **Build and Deploy Development APK:**
   ```bash
   # In Unity Editor: File → Build and Run
   # Or via CLI:
   # unity -batchmode -quit -buildAndroidPlayer Assets/ -logFile -
   ```

3. **Test on Multiple Devices:**
   - Test on minimum API level (28) device
   - Test on latest API level (34) device
   - Test on tablets (different aspect ratios)
   - Test on low-end hardware (2GB RAM)

4. **Performance Profiling on Device:**
   ```plaintext
   - Use Profiler (Window → Analysis → Profiler)
   - Monitor: CPU, GPU, Memory, Network
   - Identify bottlenecks: DrawCalls, vertices, bandwidth
   ```

## Phase 6: Production Build Optimization

1. **Enable App Bundle (AAB) for Google Play:**
   ```plaintext
   File → Build Settings
   → Build App Bundle (Google Play)
   → Configure versioning
   → Build
   ```

2. **Obfuscate Code:**
   - **Assets → External Libraries → Google Play Services**
   - **Enable ProGuard/R8 obfuscation**
   - **Google Play Console → Configure obfuscation mapping**

3. **Sign APK Properly:**
   ```plaintext
   Player Settings → Publishing Settings
   → Create or import keystore
   → Set keystore password
   ```

## Phase 7: Post-Launch Monitoring

1. **Set Up Crash Reporting:**
   - Integrate Firebase Crashlytics
   - Or use Sentry SDK for Android

2. **Monitor Performance Metrics:**
   - Android Vitals in Google Play Console
   - Track: Crash rate, ANR (Application Not Responding), StuckFrames

3. **User Analytics Integration:**
   - Use Firebase Analytics or Adjust SDK
   - Track: DAU, retention, crash funnels

## Verification Checklist

- [ ] All required SDK components installed
- [ ] Player Settings configured for target device range
- [ ] Performance profiler shows <16.67ms per frame (60 FPS)
- [ ] Device testing completed on 3+ device types
- [ ] App bundle builds without errors
- [ ] Code obfuscation working (symbols available)
- [ ] Crash reporting configured
- [ ] App published to Google Play Console successfully

## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| "Android SDK not found" | Set Editor → Preferences → External Tools → Android SDK path |
| Build fails with "Gradle error" | Update Gradle, clear Library folder, rebuild |
| APK too large (>100MB) | Enable compression, use asset bundles, remove unused assets |
| Performance issues on low-end devices | Lower texture resolution, reduce draw calls via batching |
| Permission denial crashes | Implement runtime permission requests (API 23+) |
