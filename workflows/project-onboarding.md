# Project Onboarding Workflow

Get new team members up to speed quickly with automated project discovery and setup.

## 1. Trigger Onboarding

Tell the agent:
- "Onboard me to this project"
- "I'm new here, help me understand the codebase"
- "Set up my dev environment for this project"
- "Give me a project tour"

## 2. Project Discovery (Agent Action)

The agent automatically scans and summarizes:

// turbo
```bash
echo "=== Project Discovery Report ==="
echo ""

ls -la | head -20
```

## 5. Code Convention Summary

The agent analyzes existing code to extract conventions:

### Naming Patterns Found

```csharp
// Fields
private int _privateField;           // _camelCase
[SerializeField] private int _serializedField;

// Properties
public int PublicProperty { get; }   // PascalCase

// Methods
public void DoSomething() { }        // PascalCase

// Events
public event Action OnSomething;     // On + PascalCase
public UnityEvent SomethingHappened; // PascalCase + past tense
```

### File Organization

```
ClassName.cs
├── Constants/Readonly
├── Serialized Fields
├── Private Fields
├── Properties
├── Unity Lifecycle (Awake, Start, Update...)
├── Public Methods
├── Private Methods
└── Event Handlers
```
