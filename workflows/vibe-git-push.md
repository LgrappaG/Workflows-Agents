# Vibe Git Push Workflow

This workflow utilizes the `commit` and `git-pushing` skills from `antigravity-awesome-skills` to instantly analyze your workspace changes, write a meaningful commit message, and push it to your GitHub repository.

Perfect for keeping your flow state unbroken during rapid VR prototyping.

// turbo-all
## 1. Stage All Changes

First, all current modifications in the Unity project are staged.

```bash
git add .
```

## 2. Generate Commit Message and Commit

The agent will read the `git diff` and automatically generate a conventional commit message analyzing what has changed (e.g., new scripts, modified metadata, layout changes).

```bash
# Agent Action:
# Evaluate the output of `git diff --cached`
# Formulate a concise and descriptive commit message automatically.
# Execute the commit.
git commit -m "Auto-Commit generated by AI Agent Workflow based on git diff Analysis"
```

## 3. Push to Remote

Finally, push the committed changes to your current branch on origin.

```bash
git push
```
