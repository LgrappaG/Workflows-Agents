# /unity-2d-setup

Bootstrap a Unity 2D project with the full production stack: URP 2D Renderer, Pixel Perfect Camera, Sprite Atlases, Cinemachine 2D, and Physics2D configuration. Uses `@unity-2d-expert` for all 2D-specific decisions.

---

## Prerequisites

- Unity 6 LTS (or 2022 LTS) with Package Manager access
- URP template selected at project creation (or URP manually installed)

---

## Steps

### Step 1: Package Installation

Open `Window → Package Manager` and install:

```
✅ Universal RP (URP)
✅ Cinemachine
✅ 2D Animation (for skeletal 2D, optional)
✅ 2D Tilemap Editor (included by default)
✅ Input System (replace legacy Input Manager)
```

---

### Step 2: Configure URP for 2D

1. In `Assets/Settings/`, create a **2D Renderer Data** asset:
   - `Create → Rendering → URP 2D Renderer Data`
   - Name it `URP-2D-Renderer`

2. Open your **URP Asset** (`UniversalRenderPipelineAsset`) and set:
   - Renderer List → assign `URP-2D-Renderer`
   - HDR: **Off** (not needed for 2D)
   - MSAA: **Off** (use post-AA instead for pixel art)

3. Activate `@unity-2d-expert` for any URP 2D lighting questions.

---

### Step 3: Pixel Perfect Camera Setup

Select `Main Camera` and add component:
- `Pixel Perfect Camera`
  - Assets PPU: `16` (retro) or `32` (higher res)
  - Reference Resolution: e.g., `320 × 180` (16:9 base)
  - Upscale Render Texture: ✅
  - Pixel Snapping: ✅
  - Crop Frame: **None**

> If not using pixel art, skip this step and use a standard `Camera` with orthographic projection.

---

### Step 4: Sorting Layer Setup

In `Edit → Project Settings → Tags and Layers → Sorting Layers`, add:

```
Background
Tilemap_BG       ← Background tiles
Tilemap_FG       ← Foreground tiles (behind player)
GameObjects      ← Enemies, items, pickups
Player
Tilemap_Overlay  ← Foreground tiles (in front of player)
UI               ← (default)
```

---

### Step 5: Physics2D Configuration

`Edit → Project Settings → Physics 2D`:
- Set **Gravity**: `(0, -20)` for snappier platformer feel (default -9.81 feels floaty)
- Open **Layer Collision Matrix** and disable:
  - Player ↔ Player (if multiplayer)
  - Enemy ↔ Enemy (if enemies shouldn't collide)
  - UI layer ↔ all physics layers
- **Simulation Mode**: Fixed Update (default — correct for Rigidbody2D)

---

### Step 6: Sprite Atlas Setup

```
Assets/
└── Art/
    └── Atlases/
        ├── Environment.spriteatlasv2   ← tiles, backgrounds
        ├── Characters.spriteatlasv2    ← player, enemies
        └── UI.spriteatlasv2            ← UI icons, buttons
```

1. `Create → 2D → Sprite Atlas`
2. Set **Type**: Master
3. Max Texture Size: `2048`
4. Format: Platform overrides → Android: `ASTC 6×6`, iOS: `ASTC 6×6`, PC: `DXT5`
5. Pack on `Ctrl+Shift+T` in Editor. Enable **Always Include in Build**.

Activate `@unity-2d-expert` for atlas batching issues or import settings.

---

### Step 7: Cinemachine 2D Camera

1. `GameObject → Cinemachine → 2D Camera (CinemachineVirtualCamera)`
2. Configure:
   - **Body**: Framing Transposer
   - **Aim**: Do Nothing
   - Follow: assign Player transform
   - Dead Zone Width/Height: `0.1` (small dead zone for responsive feel)

3. Add **Cinemachine Confiner 2D**:
   - Create a `PolygonCollider2D` that traces the level boundary
   - Assign to Confiner's `Bounding Shape 2D`

---

### Step 8: Folder Structure

```
Assets/
├── Art/
│   ├── Atlases/
│   ├── Sprites/
│   └── Tilemaps/
├── Audio/
├── Prefabs/
│   ├── Characters/
│   ├── Items/
│   └── UI/
├── Scenes/
├── Scripts/
│   ├── Player/
│   ├── Enemies/
│   ├── Systems/
│   └── UI/
├── Settings/          ← URP assets, Input Actions
└── Tiles/             ← TileBase assets, RuleTile assets
```

---

### Step 9: Verify with @unity-2d-expert

```
Use @unity-2d-expert to verify:
- Is sprite batching working? (Stats window → Batches < 50)
- Is Pixel Perfect Camera showing correct resolution?
- Is Physics2D gravity set for intended game feel?
```
