# Accessibility Audit Workflow

Comprehensive accessibility review using `@accessibility-expert`.

## 1. Define Audit Scope

Tell the agent what to audit:
- "Full accessibility audit for my VR game"
- "Check WCAG compliance for UI"
- "Review comfort settings for VR"
- "Audit for colorblind accessibility"

## 2. Accessibility Categories

### A. Visual Accessibility

| Feature | Priority | Status |
|---------|----------|--------|
| High contrast mode | High | |
| Colorblind modes (Deuteranopia, Protanopia, Tritanopia) | High | |
| Text size scaling | High | |
| Screen reader support | Medium | |
| Reduced motion option | Medium | |
| Flash/strobe reduction | High | |

### B. Audio Accessibility

| Feature | Priority | Status |
|---------|----------|--------|
| Subtitles/Captions | High | |
| Speaker identification | High | |
| Sound effect captions | Medium | |
| Visual sound indicators | Medium | |
| Mono audio option | Low | |
| Volume controls per category | High | |

### C. Motor Accessibility

| Feature | Priority | Status |
|---------|----------|--------|
| Button remapping | High | |
| Hold vs Toggle options | High | |
| One-handed mode | Medium | |
| Auto-aim/assist options | Medium | |
| Adjustable timing windows | Medium | |
| Reduced QTE difficulty | Medium | |

### D. VR Comfort

| Feature | Priority | Status |
|---------|----------|--------|
| Comfort vignette | High | |
| Snap turn option | High | |
| Teleport locomotion | High | |
| Seated mode | High | |
| Height calibration | High | |
| IPD adjustment support | Medium | |

### E. Cognitive Accessibility

| Feature | Priority | Status |
|---------|----------|--------|
| Tutorial skip option | Medium | |
| Difficulty options | High | |

| Pause at any time | High | |

## 3. Automated Checks

// turbo
```bash
echo "=== Accessibility Audit ==="
echo ""
echo "Searching for accessibility-related code..."
grep -r "colorblind\|accessibility\|subtitle\|caption" --include="*.cs" Assets/ 2>/dev/null | head -20
echo ""
echo "Checking for settings files..."
find Assets -name "*Settings*" -o -name "*Options*" -o -name "*Accessibility*" 2>/dev/null | head -10
echo ""
echo "UI scale references..."
grep -r "fontSize\|scale\|textSize" --include="*.cs" Assets/ 2>/dev/null | head -10
```

## 4. Colorblind Testing

The agent checks color usage:

```markdown
### Color Usage Analysis

| Element | Colors Used | Issue | Fix |
|---------|-------------|-------|-----|
| Health bar | Red/Green | Deuteranopia conflict | Add patterns/icons |
| Team indicators | Red/Blue | OK | - |
| Damage numbers | Red | May need outline | Add black outline |
| Collectibles | Yellow/Orange | May blend | Increase contrast |
```

### Colorblind Simulation Filters

```csharp
public enum ColorblindMode
{
    None,
    Deuteranopia,  // Red-green (most common, 6% of men)
    Protanopia,    // Red-green
    Tritanopia     // Blue-yellow (rare)
}
```

## 5. VR Comfort Checklist

```markdown
### Motion Sickness Risk Assessment

| Feature | Risk Level | Mitigation |
|---------|------------|------------|
| Smooth locomotion | High | Offer teleport alternative |
| Smooth rotation | High | Offer snap turn alternative |
| Acceleration | Medium | Comfort vignette |
| Verticality | Medium | Avoid rapid elevation changes |
| Frame drops | High | Optimize for stable 72+ fps |
```

## 7. Implementation Checklist

```markdown
### Before Launch

#### Visual
- [ ] Colorblind modes implemented and tested
- [ ] Text scales without breaking layout
- [ ] High contrast mode available
- [ ] No flashing >3Hz without option to disable

#### Audio
- [ ] All dialogue has subtitles
- [ ] Sound effects have optional captions
- [ ] Volume sliders work correctly
- [ ] Spatial audio has fallback for mono

#### Motor
- [ ] All controls remappable
- [ ] Hold/toggle options for grips/triggers
- [ ] No actions require simultaneous buttons
- [ ] Timing windows adjustable

#### VR Comfort
- [ ] Teleport and smooth locomotion options
- [ ] Snap and smooth turn options
- [ ] Vignette adjustable
- [ ] Seated mode fully playable

#### Testing
- [ ] Tested with colorblind users
- [ ] Tested with motor-impaired users
- [ ] Tested seated vs standing
- [ ] Tested with screen readers (if applicable)
```
