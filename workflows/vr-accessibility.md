# VR Accessibility Workflow

Make your VR experience accessible to more players by implementing inclusive design patterns.

## 1. Accessibility Audit

Tell the agent what to evaluate:
- "Audit my VR project for accessibility"
- "Add comfort settings to my VR game"
- "Implement subtitles for VR"
- "Make my UI color-blind friendly"

## 2. Accessibility Categories

### 🎮 Comfort & Motion Sickness

| Feature | Priority | Description |
|---------|----------|-------------|
| Vignette during movement | High | Reduces peripheral vision during locomotion |
| Snap turn vs Smooth turn | High | Option for instant rotation |
| Teleport locomotion | High | Alternative to smooth movement |
| Seated mode | Medium | Adjust height and reach for seated play |
| One-handed mode | Medium | Play with single controller |
| Stationary boundary | Low | Option to disable guardian warnings |

### 👁️ Visual Accessibility

| Feature | Priority | Description |
|---------|----------|-------------|
| High contrast mode | High | Increase UI contrast |
| Colorblind modes | High | Deuteranopia, Protanopia, Tritanopia filters |
| Text size scaling | High | Larger UI text option |
| Crosshair/pointer customization | Medium | Size, color, style options |
| Flash/strobe reduction | Medium | Limit intense visual effects |
| Object highlighting | Low | Outline interactables |

### 👂 Audio Accessibility

| Feature | Priority | Description |
|---------|----------|-------------|
| Subtitles/Captions | High | All dialogue with speaker identification |
| Visual sound indicators | High | Show direction of important sounds |
| Volume sliders | High | Separate music, SFX, voice volumes |
| Mono audio option | Medium | For single-ear hearing |
| Haptic alternatives | Medium | Vibration for audio cues |

### 🖐️ Motor Accessibility

| Feature | Priority | Description |
|---------|----------|-------------|
| Button remapping | High | Customize all controls |
| Hold vs Toggle | High | Option for grip, triggers |
| Simplified controls | Medium | Reduce required inputs |
| Auto-aim assist | Medium | Help with precision tasks |
| Gesture sensitivity | Medium | Adjust required motion range |

## 3. Comfort Settings Implementation

### Vignette System

```csharp
// VignetteController.cs
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class VignetteController : MonoBehaviour
{
    [SerializeField] private Volume _postProcessVolume;
    [SerializeField] private float _vignetteIntensity = 0.4f;
    [SerializeField] private float _fadeSpeed = 5f;

    private Vignette _vignette;
    private float _targetIntensity;

    private void Start()
    {
        _postProcessVolume.profile.TryGet(out _vignette);
    }

    public void SetMoving(bool isMoving)
    {
        _targetIntensity = isMoving ? _vignetteIntensity : 0f;
    }

    private void Update()
    {
        if (_vignette != null)
        {
            _vignette.intensity.value = Mathf.Lerp(
                _vignette.intensity.value,
                _targetIntensity,
                Time.deltaTime * _fadeSpeed
            );
        }
    }
}
```

### Snap Turn Option

```csharp
// TurnProvider.cs
public class TurnProvider : MonoBehaviour
{
    public enum TurnMode { Smooth, Snap }

    [SerializeField] private TurnMode _turnMode = TurnMode.Snap;
    [SerializeField] private float _smoothTurnSpeed = 60f;
    [SerializeField] private float _snapTurnAngle = 45f;

    public void SetTurnMode(TurnMode mode) => _turnMode = mode;

    public void ApplyTurn(float input)
    {
        if (Mathf.Abs(input) < 0.5f) return;

        float rotation = _turnMode switch
        {
            TurnMode.Smooth => input * _smoothTurnSpeed * Time.deltaTime,
            TurnMode.Snap => Mathf.Sign(input) * _snapTurnAngle,
            _ => 0f
        };

        transform.Rotate(0, rotation, 0);
    }
}
```

## 4. Colorblind Filter Implementation

```csharp
// ColorblindFilter.cs
public enum ColorblindMode
{
    None,
    Deuteranopia,  // Red-green (most common)
    Protanopia,    // Red-green
    Tritanopia     // Blue-yellow
}

public class ColorblindFilter : MonoBehaviour
{
    [SerializeField] private Material _colorblindMaterial;

    private static readonly Matrix4x4 DeuteranopiaMatrix = new Matrix4x4(
        new Vector4(0.625f, 0.375f, 0f, 0f),
        new Vector4(0.7f, 0.3f, 0f, 0f),
        new Vector4(0f, 0.3f, 0.7f, 0f),
        new Vector4(0f, 0f, 0f, 1f)
    );

    public void SetMode(ColorblindMode mode)
    {
        // Apply color matrix to post-process shader
        _colorblindMaterial.SetMatrix("_ColorMatrix", GetMatrix(mode));
    }

    private Matrix4x4 GetMatrix(ColorblindMode mode) => mode switch
    {
        ColorblindMode.Deuteranopia => DeuteranopiaMatrix,
        // ... other matrices
        _ => Matrix4x4.identity
    };
}
```

## 5. Subtitle System

```csharp
// SubtitleManager.cs
public class SubtitleManager : MonoBehaviour
{
    [SerializeField] private TextMeshProUGUI _subtitleText;
    [SerializeField] private Image _background;
    [SerializeField] private float _displayDuration = 3f;

    [Header("Accessibility Options")]
    [SerializeField] private bool _showSpeakerName = true;
    [SerializeField] private bool _showSoundEffects = true;
    [SerializeField] private float _textScale = 1f;

    public void ShowSubtitle(string speaker, string text, Color speakerColor)
    {
        string display = _showSpeakerName
            ? $"<color=#{ColorUtility.ToHtmlStringRGB(speakerColor)}>{speaker}:</color> {text}"
            : text;

        _subtitleText.text = display;
        _subtitleText.fontSize = 24 * _textScale;

        CancelInvoke(nameof(HideSubtitle));
        Invoke(nameof(HideSubtitle), _displayDuration);
    }

    public void ShowSoundEffect(string description)
    {
        if (!_showSoundEffects) return;
        ShowSubtitle("", $"[{description}]", Color.gray);
    }

    private void HideSubtitle()
    {
        _subtitleText.text = "";
    }
}
```

### Settings ScriptableObject

```csharp
// AccessibilitySettings.cs
[CreateAssetMenu(fileName = "AccessibilitySettings", menuName = "Settings/Accessibility")]
public class AccessibilitySettings : ScriptableObject
{
    [Header("Comfort")]
    public bool enableVignette = true;
    public TurnProvider.TurnMode turnMode = TurnProvider.TurnMode.Snap;
    public bool seatedMode = false;

    [Header("Visual")]
    public ColorblindMode colorblindMode = ColorblindMode.None;
    public float uiScale = 1f;
    public bool highContrast = false;
    public bool reduceFlashing = false;

    [Header("Audio")]
    public bool subtitlesEnabled = true;
    public bool showSpeakerNames = true;
    public bool showSoundEffects = true;
    public float subtitleScale = 1f;

    [Header("Motor")]
    public bool holdToGrip = true;  // false = toggle
    public bool holdToTrigger = true;
    public float gestureDeadzone = 0.1f;

    public void Save()
    {
        string json = JsonUtility.ToJson(this);
        PlayerPrefs.SetString("AccessibilitySettings", json);
    }

    public void Load()
    {
        string json = PlayerPrefs.GetString("AccessibilitySettings", "");
        if (!string.IsNullOrEmpty(json))
        {
            JsonUtility.FromJsonOverwrite(json, this);
        }
    }
}
```

## 7. Testing Checklist

Before release, verify:

### Comfort
- [ ] Vignette activates during all locomotion types
- [ ] Snap turn works correctly at different angles
- [ ] Teleport arc is visible and responsive
- [ ] Seated mode adjusts all interactions appropriately

### Visual
- [ ] All UI readable with each colorblind filter
- [ ] Text scales correctly without breaking layout
- [ ] High contrast mode makes all elements visible
- [ ] No flashing exceeds 3Hz when reduction enabled

### Audio
- [ ] All dialogue has subtitles
- [ ] Sound effects have optional captions [footsteps], [door creaks]
- [ ] Speaker identification is accurate
- [ ] Visual indicators show sound direction

### Motor
- [ ] Every action achievable with remapped controls
- [ ] Hold/toggle options work for all grip interactions
- [ ] One-handed mode completes full experience
