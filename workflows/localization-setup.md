# Localization Setup & Multi-Language Framework

This workflow implements a production-ready localization system for global audiences, including language table management, TextMesh Pro font setup, and runtime language switching.

## Prerequisites

- TextMesh Pro 3.0+ (built-in to Unity 2022+)
- Unity Localization package (via Package Manager)
- Language data (CSV, Google Sheets, or JSON)
- Font files for each language (especially CJK: Chinese, Japanese, Korean)
- 2-3 weeks for professional translation services

## Context

Localization goes beyond translation - it requires managing UI layouts for different text lengths, cultural adaptation, and runtime language switching for global reach and market expansion.

## Phase 1: Install Localization Packages

1. **Add Unity Localization Package:**
   ```bash
   # Window → TextMesh Pro → Import TMP Essential Resources
   # Window → TextMesh Pro → Import TMP Examples & Extras

   # Window → Package Manager
   # Search: "localization"
   # Install: Localization package (latest version)
   ```

2. **Import Smart Font Asset Package (Optional):**

   ```plaintext
   Asset Store → Search "TextMesh Pro CJK Fonts"
   Import pre-built CJK font assets (saves time)
   ```

3. **Verify Installation:**
   ```bash
   # Check Assets/Localization folder exists
   # Check Assets/TextMesh Pro/Resources folder populated
   ```

## Phase 2: Create Localization Tables Structure

1. **Set Up Localization Project:**
   ```plaintext
   Window → Localization → Dashboard
   - Create New Project (or open existing)
   - Select locales: English, Spanish, French, German, Chinese, Japanese, Korean, Portuguese, Italian, Russian
   - Use standard ISO 639-1 codes: en, es, fr, de, zh, ja, ko, pt, it, ru
   ```

2. **Create String Tables:**
   ```plaintext
   Right-click in Project window → Localization → Create String Table Collection
   Create tables for:
   - UIStrings (buttons, menus, system messages)
   - GameplayStrings (in-game text, descriptions)
   - MenuStrings (main menu, settings, credits)
   - ErrorStrings (error messages, warnings)
   - DialogueStrings (NPC dialogue, narrative text)
   ```

3. **Populate String Table with Keys:**
   ```plaintext
   Example strings:
   - ui/play_button: "Play"
   - ui/settings_button: "Settings"
   - gameplay/level_complete: "Level {0} Complete!"
   - dialogue/npc_greeting: "Hello, adventurer!"

   Note: Use {0}, {1} for variables/formatting
   ```

## Phase 3: Configure TextMesh Pro for Multi-Language

1. **Create Fallback Font:**
   ```plaintext
   TextMesh Pro → Font Asset Creator
   - Import base English font (Arial, Roboto, etc.)
   - Create Font Asset for English
   - Settings: Font Size: 36, Padding: 5
   - Generate and save as: Resources/Fonts/DefaultFont
   ```

2. **Create Character-Rich Font for CJK (Chinese/Japanese/Korean):**
   ```plaintext
   For maximum character coverage:
   - Download Noto Sans fonts from Google Fonts
   - TextMesh Pro → Font Asset Creator
   - Source Font: NotoSansCJK-Regular.ttf
   - Limited Character Set: "CJK Unified Ideographs Essential Set"
   - Resolution: 256 (high quality)
   - Padding: 5
   - Atlas Resolution: 4096x4096
   - Save as: Resources/Fonts/NotoSansCJK
   ```

3. **Set Up Fallback System:**
   ```plaintext
   TextMesh Pro Settings (TMP Settings.asset):
   - Enable Fallback Font Assets
   - Primary Font: DefaultFont
   - Fallback 1: NotoSansCJK (for CJK characters)
   - Order matters - TextMesh Pro tries in sequence
   ```

## Phase 4: Implement Runtime Localization in UI

1. **Create Localization Manager:**
   ```csharp
   using UnityEngine;
   using UnityEngine.Localization.Settings;
   using UnityEngine.Localization;

   public class LocalizationManager : MonoBehaviour
   {
       public static LocalizationManager Instance { get; private set; }
       public LocalizedString CurrentLocaleString { get; private set; }

       private void Awake() {
           if (Instance != null && Instance != this) {
               Destroy(gameObject);
               return;
           }
           Instance = this;
           DontDestroyOnLoad(gameObject);
       }

       public void SetLocale(int localeIndex) {
           LocalizationSettings.SelectedLocale = LocalizationSettings.AvailableLocales.Locales[localeIndex];
           PlayerPrefs.SetInt("SelectedLocale", localeIndex);
           PlayerPrefs.Save();
       }
   }
   ```

2. **Update UI Text Components:**
   ```csharp
   using UnityEngine.Localization;
   using UnityEngine.UI;

   public class UIButtonLocalized : MonoBehaviour
   {
       public LocalizedString localizedString;
       private Text textComponent;

       private void Start() {
           textComponent = GetComponent<Text>();
           // Subscribe to locale changes
           LocalizationSettings.SelectedLocaleChanged += OnLocaleChanged;
           OnLocaleChanged(LocalizationSettings.SelectedLocale);
       }

       private void OnLocaleChanged(Locale locale) {
           textComponent.text = localizedString.GetLocalizedString();
       }

       private void OnDestroy() {
           LocalizationSettings.SelectedLocaleChanged -= OnLocaleChanged;
       }
   }
   ```

3. **Handle Dynamic Text with Placeholders:**
   ```csharp
   public void DisplayLevelComplete(int levelNumber) {
       var localizedString = new LocalizedString { TableEntryReference = "Strings/UIStrings", TableReference = "Level_Complete" };
       string formatted = string.Format(localizedString.GetLocalizedString(), levelNumber);
       levelCompleteText.text = formatted;
   }
   ```

## Phase 5: Layout Adaptation for Different Languages

1. **Create Language-Specific UI Layouts:**
   ```plaintext
   Challenge: German text is ~35% longer than English
   Solution: Use Layout Groups with flexible sizing

   Recommended approach:
   - Use Horizontal/Vertical Layout Group components
   - Set "Child Force Expand" appropriately
   - Provide min/max width constraints
   ```

2. **Handle Text Direction (RTL for Arabic/Hebrew):**
   ```csharp
   public void SetupUIDirection(Locale locale) {
       bool isRTL = locale.LocaleName.Contains(new LocaleIdentifier("ar")) ||
                    locale.LocaleName.Contains(new LocaleIdentifier("he"));

       RectTransform[] allTexts = GetComponentsInChildren<RectTransform>();
       foreach (var rect in allTexts) {
           if (isRTL) {
               rect.anchorMin = new Vector2(1, rect.anchorMin.y); // Right anchor
               rect.offsetMin = new Vector2(-100, rect.offsetMin.y);
           }
       }
   }
   ```

## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| CJK characters display as squares | Verify fallback font configured, ensure NotoSansCJK imported |
| Text runs off screen in German/Spanish | Use Layout Groups, enable "Child Force Expand", test width constraints |
| RTL text displays backwards | Manually set anchor and offset for RTL locales |
| Missing characters in some languages | Check font atlas resolution (increase to 4096 if needed) |
| Performance drops with many locales | Lazy-load only active locale fonts, disable unused language fonts |
