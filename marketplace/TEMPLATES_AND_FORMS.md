## TEMPLATE 4: CONTRIBUTOR CODE OF CONDUCT AGREEMENT

**Required for:** All Tier 2+ contributors
**Frequency:** Annual confirmation + on violations

```markdown
# MARKETPLACE CONTRIBUTOR AGREEMENT

By publishing skills on .agents marketplace, you agree to:

## 1. Quality Commitment ✓
- Maintain code quality and security standards
- Respond to issues within 7 days (or less)
- Keep dependencies updated
- Document breaking changes
- Test thoroughly before publishing

## 2. Community Standards ✓
- Treat all contributors with respect
- Provide constructive feedback
- Share knowledge generously
- Follow the Code of Conduct
- Escalate conflicts professionally

## 3. Security & Privacy ✓
- No hardcoded secrets or credentials
- No collection of user data without consent
- GDPR/CCPA compliance in your skills
- Report security issues responsibly
- Participate in security audits

## 4. Licensing & IP ✓
- Original work or properly licensed
- Clear license statement
- No plagiarism or stolen code
- Respect 3rd-party licenses
- Attribute sources properly

## 5. Financial Responsibility ✓
- Accurate tax information
- No revenue fraud or manipulation
- No bot traffic or fake downloads
- Honest activity reporting
- Cooperation with audits

## 6. Maintenance Obligations ✓
- Maintain skills for required periods
- Respond to critical issues urgently
- Update for platform changes
- Sunset deprecated features properly
- Clear migration paths

## Consequences of Violations

| Violation Level | Action |
|---|---|
| **Minor** (late response, doc issues) | Warning + 30-day improvement window |
| **Moderate** (quality issues, community) | Tier downgrade + possible skill archival |
| **Major** (security, fraud) | Immediate removal + ban + legal action |

## Appeal Rights
- 30-day appeal window on all enforcement actions
- Fair hearing with neutral panel
- Clear reasoning and evidence required
- You can appeal our appeal decision (escalation)

## Your Rights
- Fair treatment and transparent process
- Clear documentation of all decisions
- Opportunity to respond and appeal
- Confidentiality of sensitive information
- Expedited resolution for urgent issues

- ☐ Revenue sharing terms
```
